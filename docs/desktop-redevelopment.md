## 视觉与兼容决策

- 产品名称为 **Yansivra**，副标题为「投资研究与复盘」。内部 `@finagent/*` 与 `FINAGENT_*` 保持兼容。
- 暖白 `#F6F5F1`、白色内容面、墨色正文和墨蓝 `#304B78`；绿色主要保留在原有金融涨跌语义中，非金融成功状态采用蓝色/文字。
- 保留深色主题与 `com.finagent.app`。品牌升级会复制资料到新目录并保留原目录备份，不覆盖已有新资料。
- 不改 Pi RPC、Agent 生命周期、凭据流程、行情采集与数据库底座；不增加全文解析、自动交易或后台复盘调度。
- 报告快照和个人判断分开；原判断不可覆盖，人工复盘只追加。没有复盘日期的记录仍可手动复盘。
- 判断保存和复盘必须等待落盘成功，失败时保留表单；同一个 requestId 更改内容返回冲突。损坏数据不能当空文件重写。
- Windows 首版产物优先 x64 目录/ZIP；不新增签名、安装器、自动更新或公共 Release 流程。不新增签名或授权配置。
